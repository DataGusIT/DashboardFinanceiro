## Sobre o Projeto

O **Dashboard Financeiro** é uma ferramenta de Business Intelligence desenvolvida em Power BI para proporcionar uma visão clara e completa da performance financeira de uma organização. O painel consolida dados de recebimentos, pagamentos e impostos para calcular métricas essenciais como lucro e margem, permitindo uma análise profunda e intuitiva.

O objetivo deste projeto é transformar planilhas financeiras complexas em um painel interativo que facilita a identificação de tendências, a avaliação da lucratividade e a tomada de decisões mais assertivas.

## ✨ Funcionalidades

### 💰 Análise de KPIs Financeiros
-   **Visão Geral:** Acompanhe os principais indicadores: **Recebimentos**, **Pagamentos**, **Impostos** e **Lucro**.
-   **Análise de Rentabilidade:** Monitore a **Margem de Lucro** para entender a eficiência financeira da empresa.
-   **Evolução Temporal:** Visualize o **Lucro por Mês** em um gráfico de tendências para identificar sazonalidades e padrões de crescimento.

### 📊 Visualizações Interativas e Avançadas
-   **Enlighten Data Story:** Uma visualização customizada que narra a história dos dados, detalhando o número de transações (incluindo PIX) e a margem associada.
-   **Filtro Visual (Image Grid):** Utilize um filtro com imagens para selecionar categorias de análise de forma mais intuitiva.
-   **Scroller por Estado:** Navegue pelos resultados de margem e desvio da margem por estado de forma dinâmica e contínua.

## Tecnologias

### Ferramentas de BI
-   **Power BI** - Plataforma principal para modelagem, análise e visualização de dados.
-   **DAX (Data Analysis Expressions)** - Linguagem utilizada para criar métricas e KPIs customizados.

### Fonte de Dados
-   **Excel / CSV** - Base de dados primária contendo os registros financeiros.

### Visuais Customizados
-   **Enlighten Data Story**
-   **Scroller**
-   **Image Grid**

## Pré-requisitos

-   [Power BI Desktop](https://powerbi.microsoft.com/pt-br/desktop/) instalado no seu computador.

## Como Usar

1.  **Clone ou baixe o repositório** para o seu computador.
2.  **Abra o arquivo `.pbix`** no Power BI Desktop.
3.  **Atualize a fonte de dados**, se necessário, para conectar o painel à sua própria base de dados (`.xlsx` ou `.csv`).
4.  **Explore o dashboard** utilizando os filtros interativos para segmentar os dados.
5.  **Publique no Power BI Service** para compartilhar o relatório online.
